# QuoteFlow 实用操作教程

这份教程面向日常负责外贸报价的业务员，也包含少量管理员操作。日常报价只需要记住一条流程：

> 选客户 → 加产品 → 填数量和单价 → 检查运费与条款 → 正式导出 → 下载 PNG 或 PDF

系统地址：[https://mm.ravirex.com](https://mm.ravirex.com)

## 1. 登录与页面导航

1. 打开系统地址。
2. 输入管理员分配的邮箱和密码。
3. 点击“登录”。

登录后左侧是功能菜单，手机端会自动变成适合小屏幕的布局：

- **报价**：新建、查找、修改和下载报价。
- **产品**：查找产品资料和图片。
- **客户**：保存常用客户资料。
- **公司资料**：管理员维护公司、银行和默认条款。
- **账号**：管理员维护登录账号。
- **备份**：管理员备份数据库和图片到 Google Drive。

> 不要多人共用一个账号。每位业务员应使用自己的账号，PI 编号才会使用正确的业务员前缀。

## 2. 第一次使用前的检查

管理员第一次使用时，建议按以下顺序检查：

1. 进入“账号”，确认自己的姓名、邮箱、PI 前缀和角色正确。
2. 将多余的默认账号设为“停用”。
3. 进入“公司资料”，检查公司名称、地址、联系方式、银行资料和默认条款。
4. 进入“产品”，确认产品 P/N、Description、Unit 和图片正确。
5. 进入“备份”，确认 Google Drive 已连接并完成一次备份。

公司资料和业务员资料会在创建报价时保存为快照。以后修改基础资料，不会改变已经创建的历史报价。

## 3. 维护产品资料

### 单个新增或修改

1. 进入“产品”。
2. 点击“新增产品”，填写 P/N、Description 和 Unit。
3. 按需要填写产品名称、常规单价和扩展属性。
4. 上传清晰的产品图片并保存。

注意事项：

- 产品身份是 P/N 加完整 Description；同一 P/N 的不同功率或规格可以作为不同变体保存。
- 常规单价会在新报价中自动带入，但每轮报价仍可以单独修改 USD 单价。
- 已经用于报价的产品不要物理删除，可以使用“归档”。
- 更换产品资料不会改变历史报价中的产品快照。

### Excel 批量导入

1. 在“产品”页面点击“批量导入”。
2. 选择 Excel 文件；如图片没有嵌入 Excel，可同时选择图片 ZIP。
3. 等待系统生成预览。
4. 检查新增、更新、重复、缺图和错误记录。
5. 对产品库中已有的相同 P/N 与 Description 选择“跳过”或“更新”。
6. 确认后正式导入。

Excel 必填列：

| 列名 | 说明 |
| --- | --- |
| `P/N` 或 `Item Number` | 产品编号 |
| `Description` | 英文产品描述 |
| `Unit` | 单位，例如 `pcs` |

可选列包括 `Name`、`Regular Price` / `Unit Price (USD)`、`Image File`。其他非空列会保存为扩展属性。系统可以直接读取 `.xlsx` 中嵌入的图片；使用 ZIP 时，优先按 `Image File` 匹配，没有填写时按 P/N 匹配图片文件名。

## 4. 维护客户资料

常用客户建议先保存，这样新建报价时可以自动带入资料。

1. 进入“客户”。
2. 点击“新增客户”。
3. 填写“内部识别名称”，例如客户简称或联系人名字。
4. 按实际情况填写 To、客户公司、Tel、Email、Tax ID 和 Ship to。
5. 点击“保存”。

只有“内部识别名称”是必填项，其他资料都可以留空。内部名称只用于自己查找客户，不会代替报价中的 To 或客户公司。

不再合作的客户可以归档。历史报价会继续保留，不受归档影响。

## 5. 创建一张新报价

### 第一步：新建报价

1. 进入“报价”。
2. 点击“新建报价”。
3. 选择客户，或选择“不选择客户”。
4. 点击“创建报价”。

系统会自动生成当天的 PI 编号和日期，例如：

```text
Mandy2026072901
```

编号由业务员 PI 前缀、上海日期和当天流水号组成，不需要手工填写。

### 第二步：填写客户与条款

检查或填写以下内容：

- To
- 客户公司
- Tel
- Email
- Tax ID
- Ship to
- Delivery Date / 交期
- Payment
- Shipping fee
- 生产周期

除 PI 编号和日期外，这些字段都可以留空。运输方式固定显示为 `UPS 6-9 working days shipping`；公司资料和默认条款会自动带入，银行信息只会出现在选择“有银行信息”的下载版本中。

### 第三步：添加产品

1. 点击“添加产品”。
2. 使用 P/N、产品名称或 Description 搜索。
3. 点击需要的产品。
4. 填写 QTY 和 Unit Price。
5. 需要时调整产品顺序或删除错误产品。

系统会自动计算：

```text
Amount = QTY × Unit Price
Total = 商品小计 + Shipping fee
```

同一个产品不能在一张报价里重复添加。相同 P/N 的不同规格会显示括号变体名称，请按规格选择正确产品。

### 第四步：保存草稿

尚未确认的报价点击“保存草稿”。草稿可以继续编辑，也可以删除。

离开页面前建议保存一次，特别是在手机或网络不稳定时。

## 6. 正式导出报价图片

确认客户资料、产品、数量、单价、运费和条款全部正确后：

1. 点击“正式导出”。
2. 在确认框中点击继续。
3. 等待页面显示“正在生成”。
4. 生成完成后按需要下载“无银行”或“有银行”的 PNG/PDF。

正式导出会同时完成两件事：

- 锁定本轮报价，防止历史内容被意外修改。
- 由导出 Worker 生成有银行/无银行各一份 PNG 和 PDF。

如果显示“导出失败”，点击“重试导出”。不要为了重试而重新创建相同报价。

## 7. 修改已锁定的报价

已经正式导出的报价不能直接修改，这是为了保证发给客户的历史版本不变。

需要改数量、价格、产品或客户资料时：

1. 打开已锁定的报价。
2. 点击“创建新一轮”。
3. 在新草稿中修改内容。
4. 保存并再次正式导出。

版本编号示例：

```text
第一轮：Mandy2026072901
第二轮：Mandy2026072901-R02
第三轮：Mandy2026072901-R03
```

旧版本及其 PNG/PDF 都会保留，可以随时查看和下载。已锁定版本也可以删除；删除后不会影响其他版本。

## 8. 日常查找与下载

在“报价”页面可以按 PI 编号或客户搜索。

- “草稿”表示仍可编辑。
- “已锁定”表示已经正式导出。
- 已生成的报价可以直接选择 PNG/PDF 以及是否带银行信息后下载。

建议发给客户前打开 PNG 再检查一次：

1. PI 编号和日期是否正确。
2. 客户姓名、电话和地址是否正确。
3. 产品图片是否完整、没有裁掉主体。
4. QTY、Unit Price、Amount 和 Total 是否正确。
5. Shipping fee、交期、付款条件是否正确。

## 9. 管理账号

只有管理员可以进入“账号”。

新增账号时需要填写：

- 姓名
- 邮箱
- PI 前缀
- 角色
- 至少 10 位的初始密码

邮箱不能与其他账号重复。PI 前缀只使用英文字母和数字，建议使用业务员英文名，例如 `Mandy`。

修改账号密码时，在“新密码”中填写新密码；留空表示不修改。离职或不再使用的账号应设为“停用”，不要继续共用。

## 10. Google Drive 备份

管理员进入“备份”页面：

1. 确认 Google Drive 显示“已连接”。
2. 点击“立即备份”或“更新云端备份”。
3. 等待“云端备份已完成，并已通过文件校验”。
4. 检查最近备份时间和完整性校验状态。

首次备份会创建 `QuoteFlow-latest-backup.tar.gz`，以后会更新同一个文件，不会不断生成重复备份。

建议在以下情况主动备份：

- 大批量导入产品后。
- 修改大量公司或客户资料后。
- 每周固定一次。
- 服务器更新或迁移前。

## 11. 常见问题

### 登录框出现旧邮箱

通常是浏览器密码管理器自动填充。可以使用无痕窗口确认，或删除浏览器中为该网站保存的登录信息。

### 产品无法添加到报价

先检查该产品是否已经在当前报价中。同一个产品不能重复添加。

### Amount 没有变化

确认 QTY 和 Unit Price 都是有效数字。Amount 和 Total 由系统自动计算，不需要手工填写。

### 正式导出后不能修改

这是正常状态。点击“创建新一轮”，系统会复制当前内容生成下一轮草稿。

### 导出一直显示“正在生成”

等待一会儿后刷新页面。如果变成“导出失败”，点击“重试导出”；仍失败时将错误提示发给管理员，不要发送账号密码或环境变量。

### 产品或客户资料修改后，旧报价没有变化

这是正常的快照机制。历史报价必须保持原样，新资料会用于之后创建的新报价。

## 12. 每日使用速查

开始工作：

1. 登录系统。
2. 检查客户资料是否已保存。
3. 新建报价并选择客户。
4. 添加产品，填写数量、单价和运费。
5. 保存草稿并检查金额。
6. 正式导出并下载需要的 PNG 或 PDF 版本。
7. 发给客户前再检查一次图片。

结束工作：

1. 确认当天需要发送的报价都已下载。
2. 未完成的报价保存为草稿。
3. 有重要数据变更时通知管理员更新 Google Drive 备份。
